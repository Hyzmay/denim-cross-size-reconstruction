# Phase 0 Segmentation Baseline Protocol

更新时间：2026-09-05

## 当前可证伪问题

在没有训练模型、没有人工框选、只输入一张图片的条件下，基于图像边缘背景统计和 GrabCut 的基线，能否稳定分割一个高对比、居中、完整可见的双裤腿轮廓？

## 最小实验

- 输入：程序生成的白色背景牛仔裤轮廓，包含裤腰、裆部和分开的左右裤腿。
- Baseline：边缘背景颜色距离、形态学清理、最大连通域。
- Changed variable：启用 GrabCut refinement。
- 固定随机性：OpenCV RNG seed `0`。
- 成功标准：默认方法对合成真值的 IoU `>= 0.95`，输出非空、单一主连通域，重复运行产生相同 mask。

该测试只证明管线和基础算法在受控条件下成立，不证明真实牛仔裤分割质量。

## 真实样本门槛

在收到真实牛仔裤图片后，先记录图片尺寸、背景、是否有人体、遮挡、视角和关键结构可见性，再固定真实样本通过标准。标准必须在运行候选方法前确定，不能根据结果事后调整。

真实样本至少检查：

- waistband、crotch、左右裤腿和 hem 是否进入 mask；
- 人体、背景、阴影和其他衣物是否误入；
- IoU、Dice 和 boundary F1（存在人工真值时）；
- foreground area ratio、连通域数、边界接触率和失败区域；
- 输入、配置、依赖版本和输入文件哈希是否完整记录。

## 已知限制

- 边缘背景必须能代表主要背景颜色。
- 复杂场景或人体穿着图可能把人体与裤子合并为同一前景。
- 裁切到画面边缘的裤子可能被背景先验削弱。
- 此阶段只有 binary pants mask，不包含结构区域或关键点。
