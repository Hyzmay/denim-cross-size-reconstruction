# 四篇重点论文与牛仔裤跨尺码项目迁移 - 教师提问版

更新时间：2026-09-06

## 先记住最重要的结论

这四篇论文都没有直接解决“单张牛仔裤图片 + 目标尺码 -> 跨尺码商品图”。它们解决的是 virtual try-on 或服装姿态追踪。

我们要做的是方法迁移，不是强行把项目说成论文复现：

| 优先级 | 论文 | 最值得迁移的思想 | 当前实现程度 |
|---:|---|---|---|
| 1 | GP-VTON | 不同裤装区域使用不同变形；用语义组合避免局部重叠；避免纹理挤压 | 只有逐行分区比例思想，没有论文网络 |
| 2 | ViTon-GUN | 先归一化到 canonical garment，再做目标变化 | 已有简化 UV/10 区，但尚未驱动 warp |
| 3 | DualFit | 先 warp 保真，再只修复必要区域；重点处理区域边界 | 已实现非生成式 warp + new-region patch + edge gate |
| 4 | GaPT-DAR | 显式二维形变比直接隐式回归更可解释；TPS 和 canonical shape prior | 尚未实现 TPS/3D，只采用显式 2D 几何方向 |

论文 PDF 位于 [`references/papers/`](../../references/papers/)。本轮已阅读四篇主论文全部 43 页，并核对核心架构图、公式、实验和消融。GP-VTON 与 ViTon-GUN 明确存在 supplementary，但当前本地目录没有对应补充材料，因此本文不会声称已核验 supplementary。

## 第一篇：GP-VTON

论文：GP-VTON: Towards General Purpose Virtual Try-on via Collaborative Local-Flow Global-Parsing Learning，CVPR 2023。

本地文件：[`GP-VTON_arXiv_2303.13756v1.pdf`](../../references/papers/GP-VTON_arXiv_2303.13756v1.pdf)

### 老师提问 1：论文原本解决什么？

### 标准回答

输入是人物图、平铺商品服装图、人体 pose/densepose 和保留区域信息；输出是人物穿上目标服装的 virtual try-on 图。它重点解决复杂姿态、相邻服装部件黏连，以及保留边界约束导致的纹理挤压。

它不是尺码放码论文，也不预测 S/M/L 对应的物理几何。

### 架构

1. 两个 FPN 分别提取人物和服装的多尺度特征。
2. LFGP 模块把服装分成局部部件。
3. Cascaded coarse/fine flow blocks 估计每个部件的 dense appearance flow。
4. Garment Parsing Block 预测全局服装 parsing。
5. 用全局 parsing 决定每个目标像素来自哪个局部 warped part。
6. Res-UNet generator 合成人物试穿结果。

在 lower-body 扩展中，论文把裤子理解为左裤腿、右裤腿和中间部分的统一三分结构。

### 关键公式和 Loss

Dynamic Gradient Truncation 用平铺服装与真实 warped garment 的 torso bounding-box 高宽比差判断穿着风格：

```text
R_style = R_warped / R_flat
R = H / W
```

- `R_style < 0.9`：使用 gradient truncation。
- `R_style > 0.95`：不截断。
- 中间区间：以 0.5 概率截断。

Warping loss 组合：warped image L1、perceptual loss、warped mask L1、parsing cross-entropy、adversarial loss、flow second-order smoothness。

Generator loss 组合：image L1、perceptual、adversarial 和 alpha-mask L1。

### Dataset、Experiments、Ablation

- VITON-HD：13,679 pairs，训练/测试为 11,647/2,032，upper-body。
- DressCode：48,392/5,400 pairs，包含 upper/lower/dresses。
- 分辨率：512 x 384。
- 指标：SSIM、LPIPS、FID、warped parsing mIoU、human evaluation。
- Ablation：比较 global flow、local flow、普通 gradient truncation 和 DGT。
- 论文还定义 `R_diff` 衡量 warped 与 flat garment 高宽比差。

消融结论：local flows 明显改善 mIoU；global parsing 消除局部部件重叠；DGT 相比固定策略更能避免纹理挤压或拉伸。

### Limitations

主论文把 limitation 和 social impact 放到 supplementary；当前尚未取得该补充材料。根据主论文输入可直接确定的限制包括：依赖 pose、densepose、garment parsing 和大量人工标注，目标是人体试穿而不是工业尺码。

### 对本项目真正可迁移的内容

1. 腰带、臀、裆、左右裤腿和裤脚不应共享一个 global transform。
2. 需要语义区域决定局部 warp 的归属，避免接缝和裤腿重叠。
3. 不应为了满足某个边界而无限挤压原纹理。
4. 应增加类似 `R_diff` 的形状比例保持指标。

### 当前代码用了多少

- [`canonical.py`](../../denim_resize/canonical.py) 划分了 10 个区域。
- [`deformation.py`](../../denim_resize/deformation.py) 在腰、臀、膝之间插值横向比例。
- 但没有 FPN、correlation、cascaded local flow、learned global parsing 或 DGT training。
- Canonical regions 目前没有传入 `warp_component()`，所以还不能称为 GP-VTON 式 region flow。

### 老师追问

为什么不直接复制 GP-VTON？

答案：它需要人物条件和训练数据，并以试穿为目标；本项目没有人物目标姿态，而有尺码表和工业几何目标。应迁移“局部形变 + 语义组合”的原则，不迁移人物生成器。

## 第二篇：GaPT-DAR

论文：GaPT-DAR: Category-level Garments Pose Tracking via Integrated 2D Deformation and 3D Reconstruction，CVPR 2025。

本地文件：[`GaPT-DAR_CVPR_2025.pdf`](../../references/papers/GaPT-DAR_CVPR_2025.pdf)

### 老师提问 1：论文原本解决什么？

### 标准回答

它处理机器人操作中的脱体服装视频。输入是相邻帧的 partial point clouds、上一帧 PC NOCS 和完整 canonical mesh NOCS；输出是下一帧 task space 中的完整 3D garment mesh/point cloud。

它不是单张 RGB 商品图方法，也不是尺码变化方法。

### 架构

1. Inter-frame Feature Fusion：共享权重 ResUNet3D 融合相邻帧点云特征。
2. Voting-based Projection：预测最优投影平面的 normal vector 和 pivot point。
3. 3D -> 2D：把 PC NOCS 和 mesh NOCS 投影到共同二维平面。
4. Garment Deformation：PointNet 特征、correlation 和 regressor 预测 TPS 参数。
5. Depth Reconstruction：从 warped 2D point sets 恢复每点深度和完整 3D garment。

### 关键公式和 Loss

投影平面由法向量 `u=(alpha,beta,gamma)` 和 pivot `q` 定义。论文使用共同方向 `e=[1,0,0]` 保证两个分支投影解释一致。

TPS 前先进行中心与尺度 pre-alignment，再预测 TPS 参数 `theta`。Garment Deformation loss 约束 TPS warped rest-state points 与目标点的梯度/位置差。

Depth Reconstruction 使用：

- Log-L1 consistency loss `L_c`。
- 基于 Sobel depth gradient 的 `L_g`，强调褶皱和细微几何。
- `L_DR = lambda_c L_c + lambda_g L_g`。

### Dataset、Experiments、Ablation

- VR-Folding：Shirt、Pants、Top、Skirt；Folding 和 Flattening。
- 每帧随机采样 4,000 partial points 和 6,000 mesh points。
- 训练 200 epochs，PyTorch，2 x Tesla T4。
- 指标：NOCS distance、Chamfer distance、correspondence distance、阈值内准确率。
- Ablation：Voting projection 优于 SVD 和固定 xOz plane；3D-2D 显式变形优于直接 3D regression。
- Robustness：测试 pose initialization noise 和更稀疏帧率。

### Limitations

- 严重自遮挡时被遮挡部分不可感知，性能下降。
- 依赖大量高质量标注和精确对齐的 3D meshes。
- 存在 synthetic-to-real gap。

### 对本项目真正可迁移的内容

1. 使用 canonical representation 明确表达“源状态 -> 目标状态”。
2. 优先显式二维变形，而不是让网络直接猜最终图。
3. TPS/mesh 可以成为当前逐行插值的下一代几何 baseline。
4. 变形应有中心、尺度预对齐和可解释参数。
5. DXF 可以在研发阶段扮演 canonical shape/mesh supervision 的角色。

### 当前代码用了多少

当前只有“显式二维几何”和“canonical 诊断”的方向相似；没有点云、NOCS 学习、Voting projection、TPS regressor、Depth Reconstruction 或 3D tracking。

### 老师追问

既然最终用户没有 DXF，为什么 GaPT-DAR 仍有价值？

答案：它告诉我们可以用 canonical shape prior 和显式 2D deformation 学习复杂非刚性变化。训练时 DXF 提供真值，部署时模型可从单图预测几何，不要求用户输入 DXF。

## 第三篇：ViTon-GUN

论文：ViTon-GUN: Person-to-Person Virtual Try-on via Garment Unwrapping，IEEE TVCG 2025。

本地文件：[`ViTon-GUN_TVCG_2025.pdf`](../../references/papers/ViTon-GUN_TVCG_2025.pdf)

### 老师提问 1：论文原本解决什么？

### 标准回答

它解决 Person-to-Person try-on：从一个人身上取出服装，再让另一个人穿上。论文认为直接从 source pose warp 到 target pose 太难，于是拆成：

```text
Person-to-Garment (P2G)
-> canonical A-Pose garment
-> Garment-to-Person (G2P)
```

它不是跨尺码商品图论文。

### 架构

1. A-Pose Estimator：依据 OpenPose 顺序构造 25 个标准 keypoints，重点使用 14 个影响服装形状的点。
2. P2G Unwrapping：双 FPN + cascaded appearance flow，把人物身上的衣服展开到 A-Pose canonical garment。
3. Shoulder-Torso Alignment：裁剪 in-shop garment 的 torso，使监督尺寸与人物上可见服装一致，避免纹理拉伸。
4. Warp Module：把 A-Pose garment warp 到目标人物 pose。
5. Generator：StyleGAN2 条件生成器；CLIP/DINO 路径保留全局颜色和纹理，warped garment multi-scale features 保留形状/细节，identity encoder 保留头手脚。

### 关键公式和 Loss

Appearance flow `u_f` 指定 canonical 输出像素从 source garment 的哪个位置采样：

```text
I_A-Pose = S(I_c, u_f)
```

P2G loss：VGG perceptual loss、flow smoothness、unwrapped garment reconstruction loss。

Warp loss：对应的 perceptual、flow smoothness 和 warped garment reconstruction loss。

Generator loss：adversarial、L1 reconstruction 和 perceptual loss。

### Dataset、Experiments、Ablation

- VITON-HD、DressCode、DeepFashion，主分辨率 512 x 384。
- Unwrap/Warp：batch 10，200 epochs，Adam，初始学习率 `1e-5`。
- Generator：batch 16，4 million iterations，学习率 `1e-4`。
- P2G 指标：FID、KID、SSIM、LPIPS 和 human evaluation。
- P2P 比较：Dior、PWS、PASTA-GAN++、CAT-DM、StableVITON。
- Ablation：专属 A-Pose estimator 优于固定 A-Pose；CLIP/DINO path 改善 logo、pattern 和 texture 保持。

### Limitations

主论文没有独立 limitation 章节。可由方法条件确定：依赖人物 pose、human parsing、配对的 in-shop garment 监督与大规模训练；最终 generator 使用 StyleGAN2，并把 diffusion-based G2P 作为 plug-and-play 下游，这与本项目当前“禁止大型生成模型”不一致。Supplementary 当前未取得。

### 对本项目真正可迁移的内容

1. 不要直接把任意输入裤型 warp 到目标；先转到稳定 canonical pants space。
2. Canonical 不能只是固定模板，应根据具体裤子的结构点自适应。
3. 需要源图到 canonical、canonical 到 target 的双向 correspondence。
4. 监督边界尺寸若不匹配，会造成纹理拉伸；训练数据必须先做几何对齐。

### 当前代码用了多少

[`canonical.py`](../../denim_resize/canonical.py) 已生成 `u/v` 和 10 个区域，这是最直接的概念迁移。但它是 mask 行扫描形成的规则坐标，不是 learned unwrapping；没有 A-Pose estimator、appearance flow training、inverse warp 或 canonical-to-target correspondence loss。

### 老师追问

为什么 canonical 是本项目比人物 generator 更重要的部分？

答案：我们的目标是稳定表达同一条裤子在不同尺码下的对应关系，而不是合成人体。Canonical space 正好隔离输入照片姿态和目标尺码几何，是四篇论文中最接近核心表示问题的思想。

## 第四篇：DualFit

论文：DualFit: A Two-Stage Virtual Try-On via Warping and Synthesis，arXiv:2508.12131。

本地文件：[`DualFit_arXiv_2508.12131v1.pdf`](../../references/papers/DualFit_arXiv_2508.12131v1.pdf)

### 老师提问 1：论文原本解决什么？

### 标准回答

它解决 upper-body virtual try-on 中的两难：warping-free diffusion 结果平滑但容易丢 logo/文字等高频细节；warping-based 方法保留细节但局部接缝和人体边界容易有伪影。

### 架构

1. 第一阶段直接使用 GP-VTON 的 LFGP warping module。
2. 从 parsing 中移除上身区域并覆盖 warped garment，构造 preserved-region input。
3. 对左袖、躯干、右袖 mask 做 3 x 3 erosion，原 mask 减 eroded mask 得到窄边界带。
4. 将人体待生成区域与部件边界带组合成 inpainting mask。
5. Res-UNet try-on module 只重建需要修复的部分，同时以 flat garment 作为外观条件。

论文公式把各区域写为交集，但从文字“combine”和 mask 语义看，工程实现时必须核对官方代码，不能盲目照抄符号。

### Loss、Dataset、Experiments、Ablation

- Try-on generator：L1 + perceptual + adversarial loss。
- VITON-HD：11,647 training，2,032 testing，768 x 1024。
- Warping flow 在 512 x 384 预测，再上采样到 1024 x 768 应用到原图。
- Warping：2 x RTX A6000，150 epochs，学习率 `5e-5`，每 GPU batch 2。
- Try-on module：4 x RTX A6000，200 epochs，学习率 `5e-4`，每 GPU batch 4。
- 指标：PSNR、SSIM、FID、LPIPS、DISTS 和 FPS。
- Ablation：加入 flat garment 条件后 SSIM/FID/LPIPS 均改善；边界 erosion 迭代 `n=5` 优于 `n=2` 和 `n=10`。

### Limitations

论文明确指出 warping segmentation 只在 VITON-HD 上训练，对极端 pose、遮挡和复杂背景的泛化有限。它仍需要人体 parsing 和成对 try-on 数据；生成阶段使用 adversarial training，不符合本项目当前约束。

### 对本项目真正可迁移的内容

1. 几何 warp 应先完成，纹理修复不能替代错误几何。
2. 大部分已经可靠的真实像素应直接保留。
3. 只对新区域、接缝和不可靠边界建立 repair mask。
4. Repair band 太窄修不好，太宽会破坏真实细节，必须通过消融选择。
5. 保留原始商品图作为纹理条件，而不是只看 warped image。

### 当前代码用了多少

- [`run.py`](../../denim_resize/run.py) 确实采用 warp -> completion -> edge refinement 的阶段顺序。
- [`completion.py`](../../denim_resize/completion.py) 只修改 new region，并允许候选回退。
- [`details.py`](../../denim_resize/details.py) 和 [`edge.py`](../../denim_resize/edge.py) 保护强边缘并修复轮廓。
- 但当前是经典 patch/residual 方法，没有 DualFit 的 Res-UNet、inpainting generator、flat-garment conditioning training 或论文 loss。

### 老师追问

为什么 DualFit 对“边缘磨损”问题特别重要？

答案：它把接缝边界视为单独 repair region，并用消融证明 repair band 宽度必须受控。当前项目的前景颜色延拓和窄范围 alpha edge 是非生成式替代方案，但仍应加入不同 band 宽度的正式消融。

## 四篇论文组合后，本项目应该形成什么

不是把四个网络堆在一起，而是形成一条符合自身任务的数据流：

```text
ViTon-GUN：建立自适应 canonical pants space
    -> GaPT-DAR：在显式 2D 空间预测可解释 deformation
    -> GP-VTON：不同语义区域使用不同 local deformation 并正确组合
    -> DualFit：保留可靠真实像素，只修复新区域和不可靠边界
```

### 与当前代码的差距

```text
当前：heuristic mask/landmarks
  -> diagnostic canonical
  -> row-wise interpolation
  -> classical patch candidate
  -> edge feathering

目标：validated segmentation/landmarks
  -> learned or geometry-supervised canonical correspondence
  -> region-constrained mesh/TPS/local flow
  -> detail-aware validity map
  -> real-texture-only selective repair
  -> physical and visual evaluation
```

## 按重要程度安排的论文学习顺序

### 第一阶段：先掌握 GP-VTON 的“为什么不能一个 global warp”

你应能解释：local flow、global parsing、DGT 分别解决什么，为什么都不是尺码预测。

### 第二阶段：掌握 ViTon-GUN 的“为什么先 canonical 再 target”

你应能解释：P2G、A-Pose、appearance flow、shoulder-torso alignment，以及它们如何改写成 pants canonicalization。

### 第三阶段：掌握 DualFit 的“哪些像素保留，哪些区域修复”

你应能解释：preserved-region、inpainting mask、narrow band、flat garment condition 和 `n=5` 消融。

### 第四阶段：掌握 GaPT-DAR 的“为什么显式 2D deformation 有价值”

你应能解释：NOCS、projection plane、TPS、depth reconstruction，并知道我们只迁移其中二维显式几何部分。

## 老师口试：论文与项目之间的 12 个关键问题

1. 四篇论文中哪一篇直接解决跨尺码？答案：没有。
2. GP-VTON 的 local flow 与当前逐行插值有什么本质差别？
3. Global parsing 为什么不是简单把三张图相加？
4. DGT 为什么只对训练阶段有意义？
5. ViTon-GUN 为什么把 P2P 拆成 P2G 和 G2P？
6. 当前 canonical 为什么还不能等同于 ViTon-GUN unwrapping？
7. GaPT-DAR 的输入为什么不能由一张 RGB 图直接提供？
8. GaPT-DAR 哪个消融支持我们优先研究显式 2D deformation？
9. DualFit 为什么同时需要 preserved region 和 repair mask？
10. Repair band 过宽会造成什么？
11. 当前项目哪些模块是论文概念迁移，哪些是独立 classical baseline？
12. 怎样设计消融才能证明某篇论文思想对跨尺码任务真的有效？

### 第 12 题的标准答案

固定同一输入、同一尺码表、同一分割和同一评估集，每次只改变一个因素：

- global warp vs region-aware warp；
- direct source-to-target vs source-to-canonical-to-target；
- no repair vs full new-region repair vs narrow-band repair；
- row interpolation vs TPS/mesh；
- no detail constraint vs seam/pocket constraint。

同时报告物理几何、纹理、边缘和人工盲评指标，不能只挑一张视觉效果图。
